## 4. 工程怎么拿到（这一步最容易出错）

工程**不是 git 仓库**，需要整包拷贝。规则如下：

| 目录/文件 | 传？ | 说明 |
|---|---|---|
| `Assets/` | ✅ | 0.2 GB，全部场景、脚本、素材、PICO 补丁都在里面 |
| `Packages/` | ✅ **必须** | 0.3 GB；`com.unity.xr.picoxr` 是嵌入包且被改过（`SpatialAudio` 编译修复、删掉坏的 Samples） |
| `ProjectSettings/` | ✅ | 包名、API 等级、图形 API 等全部配置 |
| `Tools/` | ✅ | Kinect 转向服务源码 |
| `NativePlugins/` | ✅ | BLE 插件 Java 源码 + 构建脚本 |
| `*.sln`、`*.csproj`、`.vsconfig`、`AGENTS.md` | ✅ | IDE 与 AI 协作配置 |
| `Library/` | ❌ **绝对不要** | 9.4 GB，本机缓存，换了机器会重建；传了反而报错 |
| `Temp/`、`Logs/`、`build/`、`obj/` | ❌ | 临时产物 |

压缩后通常 300–500 MB（`Assets` 0.2 GB + `Packages` 0.3 GB），用 7-Zip 打成 `.7z` 传即可。

> ⚠️ 解压路径不要带中文和空格（例如 `D:\FreeBike` 可以，`D:\我的项目\免费单车` 不行），否则 adb / Gradle / IL2CPP 偶发诡异错误。

## 5. 首次配置步骤（按顺序做）

1. 装 **Unity Hub** → 登录 → 安装 **6000.6.6f1** → 勾选 Android Build Support（含 SDK & NDK Tools、OpenJDK）。
2. 打开 Unity，登录账号，激活 Personal 许可证（Hub → 设置 → 许可证）。
3. 解压工程到 `D:\FreeBike`（或任意纯英文路径）。
4. Hub → Add → 选该目录 → 打开，**等待首次导入**（10–30 分钟，需联网）。
5. 若弹出预发布包提示：`com.unity.ai.assistant` 是 `2.20.0-pre.2`，需在 Package Manager 里开启 **Enable Pre-release Packages**。
6. 打开 `Window → Package Manager`，确认没有红色报错；`Console` 里只应有黄字。
7. `File → Build Profiles`（或 Build Settings）→ 切到 **Android**。
8. 核对 **§6 的 Player Settings 表**，逐项确认。
9. 头显开启开发者模式 + USB 调试，连 USB，运行 `adb devices` 应看到设备。
10. `Build` → 输出 APK → `adb install -r xxx.apk`，或走 SMB 共享安装。

## 6. Player Settings 核对表（必须与本机一致）

| 设置项 | 值 | 位置 |
|---|---|---|
| 包名 | `com.freebike.ride` | Player → Other Settings → Identification |
| 最低 API Level | **29**（Android 10） | Other Settings → Minimum API Level |
| 目标 API Level | 自动（取最高，当前 36） | 同上 |
| 目标架构 | **ARM64** | Other Settings → Target Architectures |
| 脚本后端 | **IL2CPP** | Other Settings → Scripting Backend |
| 图形 API | **仅 OpenGLES3**（不要 Vulkan） | Other Settings → Graphics APIs |
| Application Entry Point | **Activity**（不是 GameActivity） | Other Settings |
| MSAA | **关**（`QualitySettings` → Mobile → Anti Aliasing = 0） | URP 资产 + Quality |
| 色彩空间 | Linear | Player → Rendering |
| 默认横屏 | 是（LandscapeLeft） | Resolution and Presentation |
| 启用场景 | **只有** `Assets/BrokenVector/LowPolyRoadPack/Demo/Low Poly Road Pack Demo.unity` | Build Profiles → Scene List |
| XR Plug-in | Android 只启用 **PXR_Loader**；`OpenXRLoader` 资源存在但**不要勾选** | Project Settings → XR Plug-in Management |

> 这几条都是踩过坑之后的定论：GameActivity 会构建失败、Vulkan + Unity6 + PICO4 有已知问题、MSAA 开着会被 PICO 校验拒。

工程里有 3 处写死了本机路径，换机器要改：

| 文件 | 现在的值 | 要改成 |

| `NativePlugins\ThinkRiderBle\build.ps1` | Unity 路径 `C:\Program Files\Unity\Hub\Editor\6000.6.6f1\...` | 新机器 Unity 实际安装路径 |

## 10. 已知坑（装的时候先知道）

| 现象 | 原因 | 处理 |
|---|---|---|
| 构建报 GameActivity 相关错误 | 入口点选了 GameActivity | 改回 **Activity** |
| PICO 校验不通过 / 黑屏 | 开了 MSAA 或用了 Vulkan | MSAA 关、图形 API 只留 GLES3 |
| 报找不到 java / ndk | 装了第二套 JDK/SDK，或 Unity 模块没装全 | 卸载独立 Android Studio，重装 Unity 的 SDK & NDK 模块 |
| `adb devices` 显示 offline | 头显休眠 / USB 线不良 | 保持亮屏、确认允许调试、换后置口短线 |
| Kinect 只枚举出麦克风，没有深度相机 | USB 2.0 链路或线材问题 | 换短认证 USB3 线、直插蓝色口、避开扩展坞 |
| 首次导入卡在 Resolving Packages | 网络问题 | 挂代理或用 Unity 中国版镜像（<https://unity.cn/releases>） |
