## 3. 四个数据源的调研结论（重要，别重复踩）

目标是拿到"沿街连续拍摄、带 GPS 与朝向"的 360 序列（B 方案）。

| 源 | 结果 | 结论 |
|---|---|---|
| **Mapillary** | Graph API 匿名请求返回 500/401 | **必须注册 application 拿 client token**（免费，2 分钟），拿到后可批量拉序列 |
| **KartaView**（原 OpenStreetCam） | `photo/nearby` 返回 `400 Invalid GET request` | API 现在也需要 key，匿名不可用 |
| **Panoramax**（开源街景，法国主导） | API v4 **无需 token 可用**，返回 GeoJSON（坐标、collection、prev/next 链、CC-BY-SA 4.0） | 可用，但**指定区域没有 360**：抽查巴黎 20 张全是 4:3 平面照片。需要先找到有 360 覆盖的区域 |
| **Wikimedia Commons** | 有大量真 360 全景，API 可查（需规范 UA），**文件服务器被墙**（直连 Connection reset） | **本次采用**，走本机 Clash 代理下载 |

### 下载方法（复现用）

Wikimedia 的文件服务器 `upload.wikimedia.org` 在国内直连会被重置，但 API（`commons.wikimedia.org`）可以直连。
下载必须走代理 + HTTP/1.1 + 重试，否则大文件会半途断掉：

```powershell
curl.exe -sS -L --http1.1 --retry 5 --retry-all-errors --retry-delay 2 `
  -x "http://127.0.0.1:7897" `
  -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/131.0" `
  -o "out.jpg" "https://upload.wikimedia.org/wikipedia/commons/..."
```

> 代理端口来自本机 Clash Verge（`127.0.0.1:7897`）。换机器要改。
> 不加 `--http1.1` 会报 `schannel: server closed abruptly`，文件被截断。

### 查一个分类下的 360 全景

```
https://commons.wikimedia.org/w/api.php?action=query
  &generator=categorymembers
  &gcmtitle=Category:360°_panoramas_with_equirectangular_projection
  &gcmtype=file&gcmlimit=12
  &prop=imageinfo&iiprop=url|size|mime&format=json
```

按关键词搜并筛 2:1 比例（本次用到的方法）：

```
generator=search&gsrsearch=street panorama 360 equirectangular&gsrnamespace=6&gsrlimit=25
```

## 4. 这批素材怎么用

把它们当成一条 **120 m 的测试路线**（每 20 m 一帧，共 6 帧），验证：

1. 速度积分 → 弧长 t → 取相邻两帧；
2. 位置插值 + 朝向对齐（yaw）；
3. 5.3K / 10K / 14.4K 三档在 PICO 4 上的实际观感与帧率；
4. 车把（`BikeVisualRig`）叠在全景球内层的遮挡与比例。

这一步不需要真实 GPS，位置可以直接按等距排布写进 manifest。
